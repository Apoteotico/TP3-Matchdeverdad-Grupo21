# CONTEXTO TP3 — Grupo 21

## Asignación Docente
- **Sorteo:** S07-A
- **Startup:** Matchdeverdad (Deportes y organización de partidos)
- **Objetivo:** Organizador de fútbol 5 que ayuda a reunir diez jugadores confirmados
- **Bloque:** Candidatos y urgencia

## Sentencias Asignadas

**FRASE 1 · R1:** Si faltan jugadores y hay candidatos compatibles con la zona y el horario, el sistema propone esos candidatos al organizador.

**FRASE 2 · R2:** Si faltan jugadores, quedan menos de tres horas y no hay candidatos compatibles, el sistema alerta al organizador sin cancelar el partido automáticamente.

## Entrega
- **Fecha:** 26/11/2026
- **Producto:** Landing page + 2 flujos agénticos
- **Evaluación:** Aprobado / Desaprobado (rúbrica, sin nota numérica)
- **Tecnología:** HTML, CSS, JS (React opcional)

## Requisitos Mínimos de la Landing
1. Presentar la startup con su logo original, legible y completo
2. Las dos sentencias (R1 y R2) con una propuesta para cada una
3. Dos diagramas de flujo (uno por sentencia): datos, decisiones, acciones y resultados
4. Desplegables con detalles de cada solución (qué entra, qué se decide, qué acción, qué resultado)
5. README con integrantes, aportes, IA usada y cómo se construyó

## Reglas Clave
- La landing **no debe** integrar IA, ejecutar agentes, conectar APIs ni tener backend real
- Los flujos representan propuestas; no se implementan automatizaciones reales
- Revisión únicamente en desktop
- El logo propio del grupo es opcional
